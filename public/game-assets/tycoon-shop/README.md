# Tycoon shop equipment art

Seven original medical equipment illustrations generated for the in-game tactical buy menu using the built-in `image_gen.imagegen` tool on 2026-09-20.

Each PNG is 1536 × 1024 pixels, RGBA with generated transparency retained. The shared direction uses faceted ivory and silver materials, slate shadows, and restrained mint accents. These are inventory illustrations, not clinical diagrams.

The exact prompt for each asset and original generated path are recorded in `manifest.json`. The generated originals remain in the Codex image output directory; these project copies are the production assets.

Assets: `extra-bed.png`, `vitals-monitor.png`, `ehr-station.png`, `med-safety-scanner.png`, `lab-runner.png`, `staff-training.png`, and `simulation-room.png`.

The shop uses locally bundled Barlow Condensed (600 and 700), downloaded from
Google Fonts. Its SIL Open Font License is in `OFL-Barlow-Condensed.txt`.
The menu's text, tier costs, selection borders and purchase controls are live
HTML/CSS; the PNGs contain only the item illustrations.
